# doocs/md 排版与交付

## 文件与主题

使用 doocs/md 的实际引擎或编辑器，自定义 CSS 可以覆盖样式，不把其他渲染器伪称为 doocs/md。优先沿用用户已确认的主题；没有现成主题时，以清晰中文排版为起点，提供黑体、宋体、文楷三个版本；仅在用户要求或当前设计任务需要时查找、采用相关审美技能。

默认交付 article.md、images/、article-doocs.html、内联样式的 article-*-wechat.html、三个字体版本、font-comparison.html 和图文 ZIP。有音频时保留 audio/ 与播放器。evidence/ 保存内部来源、日志、原始素材与提示词；必要复现附件及许可可放公开包。用户自行发布。

## 阅读页的排版面板

独立 HTML 内置复制标题、复制当前排版正文、复制图片占位版。字体面板支持黑体／宋体／文楷、正文与章节字号、行距、段距、字距、强调色、对齐、代码主题和 Mac 风格圆点；提供手机宽度预览、恢复默认、设置记忆和保存当前排版 HTML。复制必须携带当前内联样式，控制面板在正文区域之外，不进入发布内容。

网页字体不会随富文本安装到微信，保留对应系统字体回退。代码配色和圆点也使用内联样式；关闭 Mac 风格时移除复制内容中的隐藏圆点。图片占位文件名与上传素材包一致。Copy 不会上传图片、音频或视频，发布前由用户在后台检查图片并插入原生媒体。

代码块保留 doocs/md 原有的三色圆点 SVG，默认开启 Mac 风格；不改为空装饰 span。沿用 pre 与 code 的显式 overflow-x:auto、code 的 -webkit-box／nowrap 及单个内部块，不把滚动只移到父层后关闭 pre 滚动，也不强制 code 为 max-content。单独设置横向溢出，避免复制时被浏览器改写为易丢失的双值 overflow 简写。检查实际 text/html 剪贴板里的圆点、配色、缩进和长行滚动；本地预览通过不等于公众号粘贴通过。已粘贴的旧代码块需重新复制替换。

遇到“本地正常、公众号异常，而原生 md 复制正常”，先比较原生输出、自定义样式和实际剪贴板 HTML。既往出现过的偏差包括：自定义导出关闭 pre 滚动，把原 SVG 换成空 span，且默认关闭 Mac 模式。优先移除这些偏差，不能仅凭预览把问题归给公众号。

修复应覆盖渲染器、默认设置、已保存设置、所有字体导出和 ZIP。旧设置迁移保留用户字体与字号；迁移完成后仍尊重用户主动切换的 Mac 状态。检查 Mac 开关切换、HTML 剪贴板中的实际 SVG、代码字符与缩进、窄屏长行能否滚动到末端。将预览、实际剪贴板检查与公众号后台粘贴验收分别记录；浏览器或工具不能完成原生富文本粘贴时，只报告已验证的范围，不宣称公众号结构告警已经消失。

## 导出时易漏的细节

- Markdown 图片用相对路径。收集资源同时处理 Markdown 图片和原始 HTML img／audio，不能漏掉文末图。
- 关闭引用外链与自动链接，必要时去除渲染后 a 元素并保留内容。所有文章 HTML 的锚点数量应为 0，不能只查 Markdown。
- 如使用文末图，单独设 width:100px、height:auto、margin:0 auto，不能被全局样式拉宽。Markdown 可保留指定源标签；离线 HTML 映射到同源本地副本或 data URI。
- 音频直接播放器，WAV 与 M4A 使用各自 MIME。单文件稿嵌入实际音频；发布编辑器不保留 HTML audio 时，由用户插入平台音频组件，不改为正文跳转链接。
- 正文变化后重建字体子集，检查新汉字与标点；指定 💬／⭐ 使用系统 emoji 回退，不能丢正文字符。
- 表格列宽按内容调整，不沿用新增表格前的旧序号。安装代码在手机宽度可横向滚动，不截断命令。
- 改图后重新渲染所有嵌入版本和 ZIP；单文件 HTML 不会随外部图片替换自动变化。
- 旧素材作内部备份，ZIP 白名单只选当前正文、预览、实际引用的资产与必要附件；不带历史草稿、原始全屏截图、缓存、模型权重。

## 交付检查

1. 四部分完整，设备要求在第二章；项目地址是开头纯文本；用户指定文末完整；无制作元信息和社区身份链接。
   完整项目文章还须核对社区检索记录与至少一个外部使用案例：原始出处可追溯，过程、结果和实际素材在正文对应。没有完成检索或只有官方展示、本机自测时，此项未通过，不能标记成稿完成。
2. 首图和封面的提示词以已完成的介绍与事实为依据，标题突出，画面表达具体机制或应用信息；三种比例分别布局且文字可读。封面同题，架构图全英文无标题／副标题且箭头正确；截图符合所描述状态。
3. 本地引用存在，单文件嵌入字节与资产一致；字体无正文缺字，音频 MIME／时长正确；ZIP 完整且无旧素材。
4. 在工具允许范围查看桌面和手机的标题、图片、表格、代码与文末。无法观察时做静态检查，并区分实际完成的检查，不能声称做过视觉验收。

检查与修改相称：单改图片无需重跑模型或重建未变字体，需要更新嵌入稿和 ZIP。复用旧校验前去掉旧项目特定数字、文件数与成功假设。

最终回复简短说明结果并提供成稿与图文包。工具及提示词按所用工具要求在交付中报告，不写进公众文章；生成文件不等于已公开发布。
