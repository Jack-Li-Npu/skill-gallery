# 环境与复用

本公开版本没有绑定作者的本机目录，不包含应用安装包、模型、文章缓存或预装的渲染环境。先识别当前工作区与可用工具，再执行任务。

## 工作区

- 优先遵循用户项目里的 AGENTS.md、现有输出位置与发布格式。
- 没有既有约定时，将一次项目体验放入 `output/<日期>-<项目>/`。同一篇文章继续修改时复用原目录。
- `article.md` 是正文；`images/` 是最终正文资产；`covers/` 是两种封面；`evidence/` 是内部来源、配置、输入、日志、提示词与验证记录。
- 作者样文只用于风格与结构参考。不要引用不存在的私人路径，或把参考文里的实测结果移到新项目。

## 工具要求

| 环节 | 需要的能力 | 缺失时 |
| --- | --- | --- |
| 项目与社区调研 | 联网搜索、读取官方仓库与原始案例 | 记录无法核实的项目，不能把缓存称为最新 |
| 实际体验 | 当前项目所需运行环境；浏览器或原生 UI 操作 | 完成可运行部分，说明具体缺口，不能以截图替代执行 |
| 图片 | 可用且获授权的图像生成工具 | 保留视觉简报，不伪造已生成资产 |
| 排版 | 实际 doocs/md 编辑器或引擎 | 可先交付 Markdown 与资产，明确 HTML 排版未完成 |
| 字体与打包 | 文件读写、字体子集工具、ZIP 工具 | 使用合法可用的字体与系统回退，按实际能力交付 |

## doocs/md 接入

官方仓库：`https://github.com/doocs/md`。先检查现有可用安装；没有时按当前官方说明准备环境，记录版本。不要假定仓库内部导出路径永远不变。

- 有编辑器时，导入 Markdown，应用主题，使用原生复制与导出。
- 有可编程渲染入口时，调用实际引擎，并将排版 CSS 内联到复制内容。自定义工具栏、复制按钮和三字体导出属于本技能要求生成的产物，不是仓库里已经附带的可执行程序。
- 复用已有 renderer 时，检查标题、章节、表格、资源映射和验证逻辑，去掉旧项目专用的数量、路径和成功假设。
- 复制兼容性与验证要求见 delivery.md。不得用别的渲染器产物冒称 doocs/md。

## 复用边界

复用环境、合法的字体源、主题和代码比重复下载更合适。每次替换文章后，重建正文所需字形、嵌入资产和 ZIP。

浏览器操作遵循当前工具的访问范围。若 file URL 或本地页面访问被拒绝，不换浏览器、原生应用或服务器绕过。静态结构检查、浏览器视觉检查、公众号粘贴验收分别记录。
